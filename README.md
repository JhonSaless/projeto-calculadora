🧮 Calculadora Web - Jhonata Sales

Um projeto simples, elegante e funcional de uma calculadora de navegador construída apenas com tecnologias fundamentais da web: **HTML, CSS e JavaScript**. 
Este projeto é ótimo para quem quer entender como estilizar elementos com CSS e realizar operações matemáticas simples no navegador utilizando JavaScript.
## 🛠️ Tecnologias Utilizadas
Este projeto não depende de bibliotecas pesadas ou frameworks. Tudo foi feito "do zero":
* **HTML5:** Estrutura da página e dos botões da calculadora (`calculadora.html`).
* **CSS3:** Responsável pelo visual, sombras, cores e pela fonte *Roboto* importada do Google Fonts (`calculadora.css`).
* **JavaScript (Vanilla):** A lógica matemática embutida diretamente nos botões utilizando a função `eval()` para calcular as expressões.
## 🚀 Como baixar e abrir no seu computador
Como é um projeto puramente *Front-end* estático, você **não precisa instalar nada especial** (como Node.js, servidores ou bancos de dados). Tudo que você precisa é do seu navegador padrão (Google Chrome, Edge, Firefox, etc.).
Aqui estão duas maneiras de você testar o projeto:
### Opção 1: Para quem não sabe usar o Git (Baixando o ZIP)
Se você é iniciante e só quer ver o projeto rodando:
1. No topo desta página do GitHub, procure um botão verde chamado **"<> Code"**.
2. Clique nele e selecione **"Download ZIP"**.
3. Escolha um local no seu computador e extraia/descompacte a pasta (clique com o botão direito sobre o arquivo `.zip` e vá em *Extrair tudo*).
4. Entre na pasta extraída, encontre o arquivo chamado `calculadora.html`.
5. Dê um **duplo clique** neste arquivo e ele abrirá magicamente no seu navegador!
